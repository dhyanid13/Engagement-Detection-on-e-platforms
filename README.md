# 🎓 Engagement Detection in online-classes

A computer vision-based system to monitor and assess student attentiveness during online lectures. This project uses deep learning models to analyze live video feeds and detect levels of engagement through facial cues and head pose estimation — enabling smarter, more responsive online education.

---

## 📌 Features

- 🧠 **Real-time Engagement Detection** using facial landmarks, head pose, and eye gaze
- 🎥 Supports **live webcam input** or **recorded lecture videos**
- 📊 Visualizes attention trends to highlight **disengaged intervals**
- ⚙️ Built with deep learning and computer vision libraries like OpenCV, Dlib, and TensorFlow/PyTorch
- 👩 Useful insights for educators to adapt teaching styles and boost participation

---

## 🛠 Tech Stack

- **Languages:** Python
- **Libraries:** OpenCV, Dlib, Mediapipe, TensorFlow/PyTorch, NumPy
- **Tools:** Jupyter Notebook / Streamlit (for visualization), Flask/FastAPI (optional backend)
